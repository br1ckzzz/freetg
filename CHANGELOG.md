# Changelog

Все заметные изменения проекта **FreeTG** документируются в этом файле.

## [0.2.2] — 2026-11-23

### Улучшено
- **Защита от утечки сокетов на Windows (`ProactorEventLoop`):** добавлена безопасная обёртка закрытия транспорта (`install_proactor_socket_guard`) и принудительный `transport.abort()` при таймаутах и ошибках подключения, чтобы оборванные соединения не накапливали зависшие дескрипторы.
- **Мгновенная отмена дозвона при уходе клиента:** `cancel_on_client_gone` (`_TrackedClientProtocol`) сразу прерывает фоновые попытки подключения к Cloudflare, если Telegram Desktop уже закрыл локальный сокет.
- **Адаптивный переход `Port 443 → Port 80` в рантайме:** при повторяющихся таймаутах TLS во время работы прокси автоматически переключается на порт 80 (как для публичного пула `.co.uk`, так и для своего Worker, если не включён жёсткий режим TLS).
- **Умный кулдаун `HTTP 429` до 00:00 UTC:** если пользовательский Cloudflare Worker исчерпал дневную квоту (`429`), он ставится на паузу до конца UTC-суток с автоматическим переключением на следующий Worker или публичный пул.
- **Единый `deadline` на подключение и WebSocket handshake:** ограничено общее время всей фазы рукопожатия вместо раздельных таймаутов.

## [0.2.1] — 2026-11-23

### Исправлено
- **Устранён шторм переподключений (`DC203` / `DC2 (media)`):** удалены проблемные `.eu.cc` домены, обрывавшие поток через 9–12 пакетов (`~2.6 КБ`); в пуле оставлены 20 стабильных `.co.uk` доменов Cloudflare CDN.
- **TCP-сегментная фрагментация TLS `ClientHello`:** при `frag_tls=True` разбиение по SNI теперь выполняется на уровне TCP-сегментов (вместо перезаписи в две TLS-записи), что устранило таймауты рукопожатий на `.co.uk` доменах через Anycast IP Cloudflare.
- **Разделены кулдауны IP и доменов:** ошибки TCP/TLS до ответа HTTP больше не отправляют домены в кулдаун вместо проблемного Anycast IP, а «тихие» обрывы потока до первого байта от DC штрафуют и конкретный домен (`mark_domain_failed`).
- **Автоподбор обхода больше не перезаписывает `frag_tls` навсегда** и проверяет как глубокий поток `DC2 (>22 КБ)`, так и связность `DC203`.
- **Чистое завершение сессии при отсутствии своего Worker:** убрана лишняя ошибка `No custom Worker configured for stateless /api fallback`, когда потоковое подключение временно недоступно.

### Добавлено
- **Выбор способа обхода в Настройках (`bypass_mode`):** добавлен явный список «Способ обхода» (`Автоподбор`, `CF Port 80`, `Встроенный WinDivert`, `Фрагментация TLS`, `Прямой / Внешний zapret`) с немедленным применением при запуске сервера и проверкой выбранного режима кнопкой «Тест соединения».

## [0.2.0] — 2026-11-22

### Добавлено
- **Встроенный публичный пул Cloudflare (23 домена):** добавлены 20 `.co.uk` доменов из `Flowseal/tg-ws-proxy` и 3 публичных `.eu.cc` домена сообщества с поддержкой всех дата-центров (`DC1..DC5`, `DC203`), кулдауном сбойных доменов и фоновым неблокирующим обновлением списка с GitHub (`refresh_public_cf_domains()`).
- **Zero-zapret режим (CF Port 80 `ws://`):** автоматический подбор параметров теперь тестирует порт `80` поверх публичного пула Cloudflare до запуска `WinDivert`, что позволяет обходить разрывы долгих TLS-соединений без прав администратора.
- **Адаптивный минималистичный UI (`_FlowLayout`):** «резиновое» перестроение кнопок без сжатия при любом размере окна, `QScrollArea`, сворачиваемая секция «Дополнительно» в Настройках.
- **Мастер подключения при первом запуске (`FirstRunDialog`):** две вкладки — «Автоматически» (в 1 клик + копирование ссылки `tg://proxy`) и «Вручную (пошагово)» с отдельными кнопками копирования для сервера, порта и ключа `dd...`.
- **Чистая выгрузка встроенного `winws.exe` + кнопки управления:** staging бинарников в `%APPDATA%\FreeTG\winws_bin` (без блокировки `_MEI...` и `.exe`), PowerShell watchdog с привязкой к PID родительского процесса и выгрузкой службы `WinDivert`, кнопки «Остановить сервер» и «Выгрузить».
- **Брендированные иконки везде:** единая фирменная иконка FreeTG установлена для окна, системного трея, toast-уведомлений, `AppUserModelID` и всех диалогов сообщений (`_show_message`).

### Изменено
- Удалены все персональные домены `workers.dev` и жёстко заданные личные секреты: `DEFAULT_WORKER_DOMAIN = ""`, при чистом старте генерируется случайный `secret`.
- Фрагментация TLS `ClientHello` (`frag_tls=True`) упрощена до 2 TLS-записей по середине SNI для стабильной совместимости с узлами Cloudflare Edge.
- Документация `README.md`, `CHANGELOG.md` и аудит конфиденциальности подготовлены для открытой публикации на GitHub.

## [0.1.0] — 2026-11-18

### Добавлено
- Ядро MTProto-прокси (`crypto.py`, `server.py`, `session.py`, `carousel.py`): поддержка протоколов `Abridged`, `Intermediate`, `Padded Intermediate` (`dd...`), ускорение AES-CTR через `cryptography` / OpenSSL `libcrypto-3` / Windows `bcrypt`.
- Потоковый WebSocket-туннель (`V1`) и stateless-карусель `worker_v2.js` (`/v2/sync` + `/v2/slice` по `6 КБ`).
- Десктопное приложение системного трея Windows на PyQt6 (`tray_app.py`, `windows_app.py`), портативный режим (`--portable` / `FreeTG_data`), автозапуск через реестр `HKCU`, CLI-режим (`run_freetg.py`) и `--selftest`.

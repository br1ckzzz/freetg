## О проекте

**FreeTG** — это open-source локальный прокси-транспорт (Windows GUI в системном трее + CLI), который принимает стандартное локальное MTProto-подключение (`dd`-секрет) от Telegram Desktop и инкапсулирует уже зашифрованный клиентский поток в короткоживущие или потоковые WebSocket / HTTP-туннели поверх CDN Cloudflare.

Проект предназначен для исследовательских целей, диагностики сетевых маршрутов и стабилизации подключения Telegram Desktop в сетях со сложной маршрутизацией или агрессивным инспектированием долгих TCP-сессий.

### Вдохновение и благодарности

Концепция локального MTProto → WebSocket моста, поддержка резервных CDN-доменов Cloudflare и интеграция с Telegram Desktop вдохновлены проектом **[Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)**.  
Рекомендуем также ознакомиться с оригинальным репозиторием автора — там доступны сборки для Linux, macOS, Android (в форках сообщества) и Docker.

## Ключевые возможности

- **Работа «из коробки» без личного Cloudflare Worker:** встроенный пул из **23 публичных Cloudflare-прокси доменов** (`.co.uk` и `.eu.cc`) с фоновым обновлением списка, кулдаунами проблемных узлов, балансировкой по Anycast IP и поддержкой всех дата-центров (`DC1..DC5`, `DC203`).
- **Адаптивный обход обрывов соединений (автоподбор):**
  1. Проверка устойчивого потока `> 22 КБ` через порт `443` (TLS).
  2. При срыве долгих TLS-сессий — автоматическое переключение на **CF Port 80 (`ws://`)** без драйверов и прав администратора (сам MTProto-трафик внутри уже дважды зашифрован клиентом).
  3. Резервный запуск встроенного пакетного модуля (`winws.exe` + `WinDivert`) при полной недоступности портов, с автоуступкой внешнему `zapret` и автоматической выгрузкой watchdog-скриптом при закрытии приложения.
- **Эфемерная карусель и протокол V2 (опционально для своего Worker):**
  - В [`worker_v2.js`](./worker_v2.js) реализован stateless-режим `/v2/sync` + `/v2/slice` с нарезкой крупных ответов по `6 КБ` через ротацию свежих сокетов и поддержкой длительного стриминга `/apiws`.
  - Можно указать собственный домен `*.workers.dev` (или несколько через запятую).
- **Минималистичный и «резиновый» интерфейс (PyQt6):**
  - Адаптивная вёрстка (`_FlowLayout`) с корректным переносом кнопок при изменении размера окна.
  - Сворачиваемая секция «Дополнительно», управление сервером («Остановить сервер» / «Запустить сервер» / «Выгрузить полностью»).
  - Пошаговый мастер первого запуска с автоматическим (`tg://proxy?...`) и ручным добавлением в Telegram Desktop.
  - Портативный режим: папка `FreeTG_data` рядом с программой или флаг `--portable`.
- **Высокая производительность криптографии:** использует системный OpenSSL (`libcrypto-3`) / Windows CNG (`bcrypt`) через `ctypes` или `cryptography` без тяжёлых сторонних рантаймов.

## Конфиденциальность и аудит данных

**FreeTG не собирает, не хранит удалённо и не передаёт никаких персональных данных или телеметрии:**

1. **Нет телеметрии и аналитики:** в коде отсутствуют SDK аналитики, трекеры, краш-репортеры и идентификаторы устройства/пользователя (`hostname`, `username`, HWID и т.п. не считываются и никуда не отправляются).
2. **Сквозное шифрование Telegram сохраняется:** FreeTG не расшифровывает содержимое переписки, звонков, медиафайлов, телефонные номера или ID аккаунтов — прокси работает только с зашифрованным MTProto-потоком (`obfuscated2` + `MTProto 2.0`).
3. **Сетевые обращения программы:**
   - Локальный порт (`127.0.0.1:1080` по умолчанию) принимает подключения только с вашего компьютера.
   - Исходящий зашифрованный MTProto-трафик направляется к выбранным узлам Cloudflare/Worker для ретрансляции в официальные IP-подсети Telegram DC.
   - При инициализации пула выполняется один фоновый `GET`-запрос без идентификаторов (`User-Agent: FreeTG/0.2.0`) к публичному списку доменов [`cfproxy-domains.txt`](https://raw.githubusercontent.com/Flowseal/tg-ws-proxy/main/.github/cfproxy-domains.txt) на GitHub.
4. **Локальные файлы:** настройки (`config.json`), технические логи соединений (`proxy.log`, без пользовательского контента) и опциональная запись автозапуска в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` хранятся исключительно на вашем ПК.

## Быстрый старт

### Вариант 1: Готовое приложение (Windows)
1. Скачайте `FreeTG.exe` (или соберите из исходников по инструкции ниже).
2. Запустите `FreeTG.exe` — в трее появится значок и откроется окно быстрого подключения:
   - **Автоматически:** нажмите **«Открыть в Telegram»** (или вставьте ссылку `tg://proxy?...` в чат «Избранное»).
   - **Вручную:** откройте `Telegram Desktop → Настройки → Продвинутые → Тип соединения → Добавить прокси → MTProto` и скопируйте **Сервер**, **Порт** и **Ключ (`dd...`)** из второй вкладки.

### Вариант 2: Запуск из исходного кода (GUI или CLI)

Требования: **Python 3.10+**.

```powershell
git clone https://github.com/br1ckzzz/freetg.git
cd freetg

# Запуск системного трея (требуется PyQt6):
pip install PyQt6
python windows_app.py

# Или лёгкий консольный режим (работает на стандартной библиотеке Python):
python run_freetg.py --host 127.0.0.1 --port 1080
```

Параметры CLI (`run_freetg.py`):
- `--port 1080` — основной порт (можно добавить ещё через `--extra-port 1088`).
- `--secret <32_hex>` — свой MTProto-секрет.
- `--worker-domain <domain>` — свой Cloudflare Worker (если не указан, используется публичный пул CF).
- `--mode auto|v1|v2` — режим работы для кастомного Worker (`worker_v2.js`).
- `--frag-tls` — фрагментация TLS `ClientHello` по SNI.
- `--pool-size 3` — число предварительно прогретых сокетов на активный DC.

## Опционально: свой Cloudflare Worker (`worker_v2.js`)

Если вы хотите использовать собственный изолированный маршрут (например, для протокола `v2` с фрагментацией ответов `/v2/sync` + `/v2/slice`):
1. Создайте бесплатный Worker в панели Cloudflare Dashboard (`Workers & Pages`).
2. Замените его код содержимым файла [`worker_v2.js`](./worker_v2.js) и нажмите **Deploy**.
3. Впишите выданный домен `*.workers.dev` в поле **«Свой Worker»** в настройках FreeTG и нажмите **«Тест соединения»**.

## Сборка `.exe` и тестирование

```powershell
# Юнит- и live-тесты (crypto, все DC 1..5 и 203, TLS-фрагментация)
python -m unittest test_freetg.py -v

# Проверка standalone-сборки через PyInstaller
pip install pyinstaller PyQt6
python -m PyInstaller --noconfirm --clean FreeTG.spec
.\dist\FreeTG.exe --selftest
```

> [!CAUTION]
> **Ложные срабатывания антивирусов**  
> Исполняемые файлы Python, упакованные через PyInstaller, а также пакетный драйвер `WinDivert64.sys`, могут вызывать эвристические ложные срабатывания у антивирусов (Windows Defender и др.). Перед запуском рекомендуется изучать открытый исходный код и собирать бинарный файл самостоятельно.
